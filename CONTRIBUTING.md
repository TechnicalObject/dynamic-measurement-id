# Contributing

Bug reports and pull requests are welcome.

- Open an [issue](https://github.com/TechnicalObject/dynamic-measurement-id/issues) first for anything bigger than a small fix.
- Make template changes in the GTM Template Editor, run the tests on the Tests tab, then export the template and replace `template.tpl`.
- Add a test scenario for any behaviour change.
- New releases are published by adding the commit SHA to `metadata.yaml`; the maintainer does this after merging.
